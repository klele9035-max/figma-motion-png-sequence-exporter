# 动画毫秒取帧导出

一个无需外部服务器、无需 FFmpeg、直接运行在 Figma Desktop 内的开发插件。

选择一个带有 **Figma Motion** 动画的 Frame 或 Group，输入指定毫秒或时间范围，插件会调用 Figma 自己的动画渲染结果，提取 PNG 单帧或 PNG 序列，并使用时间数值命名文件。

```text
前缀 + 时间数值 + 后缀 + .png
```

例如：

```text
shot_0_final.png
shot_40_final.png
shot_80_final.png
shot_100_final.png
```

## 适合什么场景

- Figma Motion 动画已经完成，不希望在 After Effects 中重新绘制和重做动画。
- 需要透明背景 PNG 序列，交给 After Effects、Premiere Pro、DaVinci Resolve 或其他合成软件。
- 需要检查动画在某一个毫秒位置的画面。
- 需要按固定毫秒间隔批量取帧，并让文件名保留请求的时间数值。
- 免费 Figma 方案无法满足高帧率或特定透明动画交付需求时，使用 PNG 序列作为中间素材。

## 主要功能

- 单帧导出：输入一个毫秒值，导出一张 PNG。
- 序列导出：设置起始时间、间隔和截止时间，导出 ZIP。
- 默认单帧时间和序列间隔均为 `40 ms`。
- 截止时间包含在结果中；当间隔不能整除截止时间时，会额外导出精确截止时间。
- 文件名前缀和后缀。
- 透明背景开关。
- 支持选择顶层 Frame，也支持选择位于顶层动画 Frame 内的 Group。
- 读取当前 Figma Motion 播放头时间。
- 记住上一次使用的参数。
- 插件窗口可拖动调整大小。
- 出错时显示明确弹窗。
- 无网络请求，所有处理都在本机完成。

## 安装

目前以 Figma 开发插件形式安装：

1. 下载本仓库 ZIP，或克隆仓库。
2. 解压后保留 `manifest.json`、`code.js` 和 `ui.html` 在同一目录。
3. 打开 Figma Desktop。
4. 进入 `Plugins → Development → Import plugin from manifest…`。
5. 选择本项目中的 `manifest.json`。
6. 安装后从 `Plugins → Development → 动画毫秒取帧导出` 启动。

不需要运行构建命令，也不需要安装 npm 依赖。

## 使用方法

### 1. 准备动画

- 动画必须使用 Figma Motion 创建。
- 动画内容必须位于页面上的顶层 Frame 中。
- 顶层 Frame 是直接放在 Page 下的 Frame，而不是另一个 Frame 内的嵌套 Frame。

### 2. 选择导出对象

一次只选择一个对象：

- 选择顶层动画 Frame：导出完整画面。
- 选择其中的 Group：插件先渲染所在的顶层动画 Frame，再裁切出 Group 的范围。

### 3. 单帧导出

1. 打开插件并选择“单帧”。
2. 输入时间，例如 `40`。
3. 可选：输入文件名前缀和后缀。
4. 可选：开启透明背景。
5. 点击“导出当前毫秒帧”。

输出示例：

```text
40.png
```

### 4. 序列导出

1. 选择“序列”。
2. 设置起始、间隔和截止时间。
3. 点击“导出 PNG 序列”。
4. 插件生成一个 `动画毫秒取帧导出.zip`。

示例参数：

```text
起始：0 ms
间隔：40 ms
截止：100 ms
```

输出：

```text
0.png
40.png
80.png
100.png
```

`100 ms` 不在 `40 ms` 的整数间隔上，因此插件会把截止时间作为最后一张补充导出。

## 透明背景的工作方式

开启“透明背景”后，插件会：

1. 临时复制顶层动画 Frame。
2. 只移除这个临时 Frame 自身的背景填充。
3. 保留内部内容、卡片、按钮、图片和其他图层。
4. 渲染完成后删除临时 Frame。

原始设计不会被修改。

如果画面中仍然有不透明底色，请检查内部是否存在铺满画面的背景矩形或嵌套 Frame 填充。插件不会自动删除这些内容图层，以免误删设计。

## 时间精度与帧率：必须阅读

插件优先请求 Figma 以 `60 fps` 渲染；当前账户、方案或 Figma 环境不支持时，自动回退到 `30 fps`。

这意味着：

- 60 fps 的帧间隔约为 `16.667 ms`。
- 30 fps 的帧间隔约为 `33.333 ms`。
- 文件名保存的是你请求的时间，例如 `40.png`。
- 图片内容来自渲染视频中最接近该时间、能够被解码的实际帧。

因此，在 30 fps 环境中请求 `40 ms`，文件仍命名为 `40.png`，但画面通常对应接近 `33.333 ms` 的已渲染帧。它不是对 Figma 连续时间轴进行数学插值。

推荐设置：

| 最终帧率 | 建议间隔 |
| --- | ---: |
| 24 fps | 41.667 ms |
| 25 fps | 40 ms |
| 30 fps | 33.333 ms |
| 60 fps | 16.667 ms |

免费方案通常以 30 fps 工作。若更重视逐帧稳定性，建议使用 `33.333 ms`；若最终 AE 合成为 25 fps，可以继续使用默认 `40 ms`，但这是一次 30→25 fps 的取样转换。

## 关于 Figma 播放头

插件可以读取当前播放头并把它填入输入框，但不能通过公开的 Figma Plugin API 修改编辑器中可见的播放头位置。

输入 `40 ms` 并导出，表示从 Figma 渲染结果中取出该时间附近的画面，不代表 Figma 界面的播放头会移动到 `40 ms`。

## 在 After Effects 中导入

不需要把每张 PNG 手动放进时间线：

1. 解压序列 ZIP，并把所有 PNG 放在同一文件夹。
2. 在 AE 中选择 `File → Import → File…`。
3. 选择第一张 PNG。
4. 勾选 `PNG Sequence`。
5. 因文件名是毫秒值且数字有间隔，建议勾选 `Force alphabetical order`，避免 AE 把数字间隔识别为丢帧。
6. 在项目面板中右键该序列，选择 `Interpret Footage → Main…`。
7. 把帧率设置为 `1000 ÷ 间隔毫秒`。

例如：

```text
40 ms → 25 fps
33.333 ms → 约 30 fps
16.667 ms → 约 60 fps
```

透明边缘若出现黑边或白边，在 `Interpret Footage` 中检查 Alpha 解释方式，通常先尝试 `Straight / Unmatted`。

## 已知限制

- 依赖 Figma Motion；普通 Prototype Smart Animate 不等同于 Figma Motion 时间轴。
- Figma 的动画视频导出只接受顶层动画 Frame，因此 Group 模式实际是渲染顶层 Frame 后裁切。
- 请求时间会受到 Figma 实际渲染帧率限制。
- 透明模式只移除顶层 Frame 自身的填充，不会猜测并删除内部背景图层。
- 复杂或超大动画的渲染和浏览器内 PNG 编码可能占用较多内存。
- 单次最多导出 1000 张 PNG。
- 序列以无压缩存储方式写入 ZIP，优先保证浏览器内兼容性，文件可能较大。
- 当前版本不会导出音频。
- 下载位置由 Figma Desktop 或系统下载设置决定；插件不能绕过宿主应用直接写入任意磁盘目录。

## 常见问题

### 提示“没有检测到可导出的 Motion 动画时间轴”

确认动画由 Figma Motion 创建，并且所选对象位于一个顶层 Frame 中。

### 选择 Group 后导出区域不正确

插件使用 Group 在顶层 Frame 中的可见边界裁切。如果 Group 超出 Frame 或包含复杂效果范围，建议改选顶层 Frame，再在 AE 中裁切。

### 开启透明背景后仍然不透明

检查内部是否有全尺寸背景矩形、图片或嵌套 Frame 填充。透明开关只移除顶层 Frame 自身的背景。

### 40.png 和 80.png 看起来一样

这通常是实际渲染帧率造成的。30 fps 每帧约 33.333 ms，相邻请求可能落到同一个解码帧。若需要稳定的 30 fps 序列，请把间隔改为 `33.333 ms`。

### Figma 界面的播放头没有移动

这是当前公开 Plugin API 的限制。插件读取播放头，但不能设置可见播放头。

## 与其他工具的区别

- 与完整 Figma 动画编辑器不同：本插件不创建动画，只导出已经存在的 Figma Motion 动画。
- 与 SVG→ProRes/PNG 命令行工具不同：本插件不需要先导出 SVG，也不需要 Node、Chrome 自动化或 FFmpeg。
- 与透明 MOV 导出器不同：本插件直接交付按时间命名的 PNG/ZIP，不需要运行本地编码服务器。
- 与录屏不同：使用 Figma 的动画渲染输出，不依赖实时屏幕录制速度。

## 隐私与网络

`manifest.json` 将网络访问设置为 `none`。插件不会上传 Figma 文件、动画视频或导出的 PNG。动画渲染、解码、裁切、PNG 编码和 ZIP 生成均在 Figma 插件环境与本机内完成。
